Description:
This is a static university website made using HTML, CSS and JavaScript. It has a header, navigation menu, home section with a blurred background image, an about section, a list of departments, a table of academic programs, an admission inquiry form and a footer. A welcome message is shown when the button on the home section is clicked.

Technologies Used:
- HTML
- CSS
- JavaScript (written inside `index.html`)

Project Structure:
```UniversityWebsite/
├── index.html
├── style.css
├── images/
│   ├── building.jpg
│   ├── campus.jpg
│   └── library.jpg
└── README.md
```

How to Run the Project:
1. Download or clone the repository:
   git clone https://github.com/Zainab313-rgb/UniversityWebsite.git
   
2. Open the project folder.

3. Double-click `index.html` to open the website in your browser.


No installation is needed.
